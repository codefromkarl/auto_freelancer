# 可靠性优化与验收

本轮根据当前源码审计实施本地修复。遵循 `docs/CORE_PRINCIPLES.md`，不提交 Git、不部署、不连接真实业务平台、不迁移业务数据库。

后续用户已授权本地 Git 提交和实际测试。本机运行验收使用隔离数据库；尚无真实平台凭证，真实投标、付款与业务数据库迁移不属于这次测试范围。

## 范围

- 统一 API 鉴权、投标内容门禁和提交前远端状态检查。
- 保存提交意图，阻止并发重复提交和结果未知后的自动重试。
- 调度器默认预览；真实提交需显式选择；要求人工确认时配置缺失必须阻断。
- 修复提案列表错误，恢复前端缺失模块，以后端实际契约接线。
- 修正本地与容器配置、文档，并用隔离测试数据验证。

## 验收清单

- [x] 缺失/错误 API Key 无法访问任何业务路由；健康检查仍可用。
- [x] 不合格文案、未知汇率、失效项目不会触发外部投标；所有创建入口共享服务门禁。
