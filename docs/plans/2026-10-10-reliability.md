## 后续提交与实际运行验收

用户授权后，初次改动已提交为 `e4125ef`。随后启动真实 Uvicorn 与 Next.js 生产服务，在本机端口 8100/3100 验证。使用独立 Chrome 测试实例，没有使用 HTTP 响应模拟或 FastAPI TestClient 代替运行进程。

运行数据为 `.runtime/smoke/runtime.db` 中的隔离样例，平台与模型地址指向不可用的本地端口。当前项目没有 `.env`、真实平台凭证或业务数据库，因此没有测试 Freelancer 账号抓取、付费模型推理或真实投标。

运行时发现并修复：

1. 项目详情强制请求远端：默认返回已有本地记录，`refresh=true` 或本地缺失时才读取远端。投标提交前的远端校验保持强制执行。
2. 消息列表/详情在会话关闭后序列化 ORM 对象导致 500：改为在会话内序列化；不存在的项目筛选返回空列表。
3. 本地项目的空 `bid_stats` 导致评分异常，平面预算字段未被识别：规则评分兼容数据库和 SDK 数据结构，并持久化实际计算的时薪。
4. 前端全局写操作默认重试：取消自动重试；浏览器确认无效投标返回 422 且只发送一次请求。
